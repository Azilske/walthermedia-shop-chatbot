# Walther Media Shop Chatbot

Wiederverwendbarer Chatbot zur Unterstützung des Kundensupports von Onlineshops der Walther Media GmbH.

## Projektziel

Ziel des Projekts ist die Entwicklung eines Chatbots, der als erste Anlaufstelle für Shopbesucher dient und häufige Kundenfragen selbstständig beantwortet.

Die Anwendung wird so aufgebaut, dass Inhalte leicht angepasst werden können und der Chatbot mit geringem Anpassungsaufwand auch für zukünftige Onlineshop-Projekte der Walther Media GmbH eingesetzt werden kann.

## Geplanter Funktionsumfang

- Beantwortung häufig gestellter Fragen (FAQ)
- Bereitstellung grundlegender Produktinformationen
- Informationen zu Bestellabläufen, Versand und Bezahlung
- Einfache Produktsuche
- Simulation einer Bestellstatusabfrage
- Einbindung als Chat-Widget in einen Onlineshop
- Leicht anpassbare Inhalte für unterschiedliche Onlineshop-Projekte

## Abgrenzung

Der Fokus des Projekts liegt auf der Bereitstellung von Informationen über den Chat.

Folgende Funktionen sind nicht Bestandteil des Projekts:

- Warenkorbfunktionen
- Zahlungsabwicklung
- Direkte Bestellungen über den Chatbot
